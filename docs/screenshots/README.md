# 界面截图 / Screenshots

此目录用于存放 README 中展示的界面截图。当前文件已由本机系统真实页面截图覆盖；后续如界面变化，按相同文件名重新截图覆盖即可（README 无需改动）。

This folder holds the screenshots shown in the README. The files here are
real screenshots captured from the local system. If the UI changes, replace
them with new screenshots using the same filenames (no README change needed).

| 文件名 / filename | 建议内容 / suggested content | 方向 / orientation |
|---|---|---|
| `dashboard.png` | PC 后台「工作台 / 首页看板」 | 横向 landscape |
| `records.png` | PC 后台「巡检记录」列表或详情 | 横向 landscape |
| `qr.png` | PC 后台「系统管理 → 巡检入口二维码」 | 横向 landscape |
| `mobile-home.png` | 手机端「选择要巡检的机房」 | 竖向 portrait |
| `mobile-inspect.png` | 手机端「单设备巡检」 | 竖向 portrait |
| `mobile-success.png` | 手机端「提交成功」 | 竖向 portrait |

> 建议：横向图约 1000×625，竖向图约 390×800，文件别太大（单张 < 500KB 更佳）。
